# Die letzte Überfahrt

Ein historischer Roman rund um den Untergang der Passagierfähre **MS Estonia**
in der Nacht vom 27. auf den 28. September 1994.

## Über dieses Projekt

Dieses Repository enthält das Manuskript eines Romans (Zielumfang
90.000–120.000 Wörter). Die historischen Ereignisse — Wetter, Ablauf der
Katastrophe, Zeitrahmen, Rettungsmaßnahmen — orientieren sich eng an den
öffentlich bekannten Fakten. **Alle Hauptfiguren sind frei erfunden.** Sie
ersetzen keine realen Opfer oder Überlebenden und stellen keine realen
Personen dar. Wo reale Amtsträger oder Institutionen berührt werden, bleiben
sie im Hintergrund oder werden nicht namentlich fiktionalisiert.

Der Roman enthält keine Verschwörungserzählungen und stellt Spekulationen
nicht als Tatsachen dar. Ein historisches Nachwort ordnet Fakt und Fiktion.

## Struktur

```
roman/
  00_konzept.md        Titel, Inhalt, Figuren, Kapitelübersicht, Zeitstrahl,
                       Deckplan, Beziehungen (die Arbeitsgrundlage)
  akt1/                Akt 1 – Vor der Überfahrt
  akt2/                Akt 2 – An Bord
  akt3/                Akt 3 – Die Nacht
  akt4/                Akt 4 – Danach
  nachwort.md          Historische Einordnung (Fakt/Fiktion)
```

## Arbeitsstand

Siehe `roman/00_konzept.md` für die vollständige Planung und die
Kapitel-Checkliste mit dem jeweiligen Fortschritt.
